## Built with

This portfolio is made using **HTML, CSS, and JavaScript**. It also includes a few interactive touches, responsive layouts, and light and dark themes. The website is hosted on **GitHub Pages**.

## Run it locally

Want to explore or make changes to the website?

1. Clone this repository:

   ```bash
   git clone https://github.com/annu1311/annu1311.github.io.git
   ```

2. Open the project folder:

   ```bash
   cd annu1311.github.io
   ```

3. Open `index.html` in your browser. That's it! No extra installation or build step is needed.

## Deployment

The site is hosted through GitHub Pages. To publish an update, make your changes, commit them, and push them to the `main` branch.
